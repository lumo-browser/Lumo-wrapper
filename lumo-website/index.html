FAQs

What makes Lumo's AI Agent unique?

Unlike simple chat sidebars, Lumo's autonomous AI operates with a Dual-Mode DOM interaction (Text & Vision). It can actually navigate websites, extract structured e-commerce data, compare products across vendors, and automate complex tasks.

It's guarded by strict safety constraints like `request_user_confirmation` for irreversible actions (purchases, account changes), keeping you in total control.

How do I download & install Lumo?

Lumo is available for desktop computers running Windows or Linux. To get started, simply download the Lumo browser for your desktop environment. Note: There is currently no release for Android and Mac.

What is Zero-Trust Mode?

Zero-Trust Mode ensures ultimate security by using partition-isolated tabs and restricting background processes. It employs an IPC Guard with strict origin validation and an Agent Guard that limits rate injections and restricts scripts to 50KB.

Does Lumo block YouTube ads?

Yes, the Lumo browser can block ads on video sites like YouTube. That includes on-page ads, pre-roll and mid-roll ads, end-card ads, and more. By blocking ads, you get a cleaner experience and faster video load.

What is Lumo Search?

Lumo Search is the private, independent search engine that’s default for most new users of the Lumo browser. It serves fast, accurate results from its own independent index of the Web, and offers unique features like a powerful AI-answer engine. Unlike some other search engines, Lumo Search doesn’t profile you; it can’t share, sell, or lose your personal data, because it’s not collected in the first place.
