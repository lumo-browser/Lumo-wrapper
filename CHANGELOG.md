# Changelog

All notable changes to Nova Browser will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Phase 1: Foundation & MVP
- Project infrastructure setup
- Electron and React integration
- Basic browser UI with tabs
- AI chat sidebar foundation
- Playwright automation framework

## [0.1.0] - TBD

### Added
- Multi-tab browser with Chromium engine
- Address bar with navigation controls
- Bookmarks and history management
- AI chat sidebar with streaming responses
- AI command bar for quick actions
- Browser automation capabilities (click, type, scroll, extract)
- Workflow execution engine
- Outcome verification system
- SQLite-based persistence layer

### Security
- Permission system with user confirmation
- Audit logging for all AI actions
- Input validation and sanitization
- Protected API key storage

### Documentation
- Architecture documentation
- API documentation
- Security guidelines
- Developer guide
