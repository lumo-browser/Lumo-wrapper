# Lumo Browser Features

Here is a comprehensive list of the features and functions available in the Lumo Browser:

## 1. Browser Core
- **Multi-tab browsing:** Manage multiple tabs with `Ctrl+T` (New Tab), `Ctrl+W` (Close Tab), and `Ctrl+Tab` navigation.
- **Chromium Rendering Engine:** Full Chromium support via Electron `<webview>` tags.
- **Smart Address Bar:** Auto-resolves URLs, performs searches, and loads internal `lumo://` pages.
- **Navigation Controls:** Back, forward, refresh, stop, and zoom controls.
- **Theme Support:** Dark, Light, and System themes with live switching.
- **Bookmarks & History:** Full bookmark manager with persistent storage and history tracking with quick access.

## 2. New Tab Dashboard
- **Customizable Widgets:** Includes a clock, search bar, shortcuts, quick notes, and top sites.
- **Personalization:** 8 preset gradient backgrounds, custom image URLs, and an accent color picker.
- **Clock:** 12/24-hour clock with date and contextual greetings.
- **Quick Notes:** Persistent scratchpad stored locally.
- **Pinned Shortcuts:** Easily add, remove, and click to navigate.

## 3. Privacy & Ad Blocking Engine
- **Zero-Dependency Ad Blocker:** Built-in engine with 150+ domain rules across 5 categories.
- **Tracker Blocking:** Blocks Google Analytics, Hotjar, Facebook, Twitter, and other trackers.
- **Ad Network Blocking:** Blocks DoubleClick, Criteo, AppNexus, and more.
- **Advanced Blocking:** Blocks cryptominers (CoinHive, etc.) and fingerprinters.
- **Live Stats:** View blocked count, allowed count, and block rate percentage.

## 4. AI Autonomous Agent
- **Modular AI Agent:** Automate multi-step web tasks (e.g., finding products, summarizing articles, form filling).
- **Agent Tools:** 14 available tools including navigating, clicking, typing, scrolling, extracting product data, etc.
- **Safety Gate:** Irreversible actions (like purchases) pause execution for user approval.
- **DOM Injection:** Reliable element targeting by capturing roles and hrefs.
- **LLM Support:** Uses OpenRouter API to support models like GPT-4o, Claude 3.5, Llama 3, and more.
- **Agent Sidebar:** Real-time streaming interface with Logs, Plan, and Compare tabs.

## 5. Keyboard Shortcuts
- Complete set of keyboard bindings for efficient browsing (e.g., `Ctrl+L` for address bar, `Ctrl+B` for bookmarks, `Alt+←/→` for history navigation, `Ctrl+Shift+A` for AI sidebar).

## 6. Advanced Settings
- **Modular Layout:** Organized into General, Home, Search Engine, Privacy & Security, Sync, and About tabs.
- **Customizable Search:** Pick your default engine and manage search/address bar suggestions.
- **Security Options:** Track cookie management, passwords, permissions, DNS over HTTPS, and data collection.
